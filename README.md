# Family Album USA Reader

《走遍美国》独立静态阅读网站。首页提供英文原文、中文译文与超纲词汇学习三个入口。课文各按源文件顺序排列 26 篇（每篇 3 幕）。

打开 `index.html` 即可离线阅读；发布到 GitHub Pages 也无需构建步骤。

文本来自用户提供的 52 个旧版 Word 文件。仅移除了每个文件末尾的 Word 页码页脚；其余正文保留原文，包括原有的标点和个别排印瑕疵。

词汇学习页收录用户提供的两份 TXT 词表，分别是“剧中出现但不在牛津3000内”（530 个词形，含 16 个语气词）和“牛津3000中但剧集未覆盖”（1572 词）。下载文件将两份原文分段合并，未添加中文释义。
